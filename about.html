What VERITY is, who built it, and why.

The idea

Every online poll asks you to trust whoever runs it. They can change a number, drop a vote, or show you a result that never happened, and you would never know. VERITY was built to remove that trust. Every poll and every vote is written to the Ethereum blockchain, where it is copied across thousands of computers and can never be edited or deleted, not even by the person who built this site. Anyone can check any result at any time. That is the whole project in one line: vote once, verify forever.

Who made it

VERITY is built and maintained by Shreya Anandhun Satish, a first-year B.Tech Computer Science student at SRM University, Ramapuram, as a project for the Web3 domain of CodeKrafters, the college coding club. It started as a club tool for honest votes on things like workshop topics and event choices, and grew into a full product: a verified smart contract, a website anyone can use, and a two-minute demo video.

What it is, and what it isn't

  • It is a transparent voting tool for small communities: clubs, classes, apartment associations, event planning.
  • It is running on Sepolia, Ethereum's test network, so voting costs nobody real money. The code would run unchanged on the main network or a cheaper one like Polygon.
  • It isn't a secret ballot. Votes are linked to wallet addresses, not names, but anyone can see which address chose which option. That openness is what makes the results checkable.
  • It isn't one person, one vote. The contract guarantees one vote per wallet, and wallets are free to create. It's a fair rule for people who know each other; for anything high-stakes it needs a membership check on top.
