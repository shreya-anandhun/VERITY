What each poll stores

FieldMeaning
titleThe question
categoryClub, College, Tech, Events, Fun or Other
options[]2 to 10 answers
votes[]One running count per option
creatorThe wallet that created the poll
endTimeWhen voting stops automatically
isOpenFalse once the creator closes it early
totalVotesAll votes cast in the poll

Every function, and who can call it

FunctionWhoWhat it does
createPoll(title, category, options, endTime)AnyoneAdds a new poll. Rejected unless it has 2 to 10 options and an end time in the future.
vote(pollId, optionIndex)Anyone, once per pollAdds one to that option. Rejected if the poll is closed, has ended, or this wallet already voted.
closePoll(pollId)That poll's creator onlyStops new votes early. Existing votes are untouched.
getPoll(pollId)Anyone, freeReads a poll and its live counts.
hasVoted(pollId, wallet)Anyone, freeTrue if that wallet has voted in that poll.
votedFor(pollId, wallet)Anyone, freeWhich option that wallet picked.
pollCount()Anyone, freeHow many polls exist.

Every change is also announced as a public event (PollCreated, Voted, PollClosed), which is what Recount and the activity feed read.

What nobody can do

  • There is no owner or admin role in the contract.
  • There is no upgrade switch: the code at this address can never change.
  • There is no function that edits or deletes a vote or a poll.
  • VERITY has no server or database: this website only reads the blockchain and asks your wallet to sign.

Verify a result yourself, without this website

  1. Open the contract's Read Contract tab on Etherscan ↗.
  2. Expand getPoll, type a poll number (the first poll is 0) and press Query.
  3. Compare the votes numbers with what VERITY shows. They come from the same place, so they always match.
  4. To see who voted, open the Events tab ↗: every Voted line is one vote.

Or press Recount on any poll: your browser re-adds every vote event and checks the total against the contract.
